# 25城青年最低工资规则补采

口径日期：2026-11-11。主表 `city_youth_wage_rules_25cities.csv` 覆盖冻结的全部25城，按14–15、16–17、18岁分列。每行保留州、城市、联邦适用层级、生效日、初始期、小费、雇主与行业/项目条件。`coverage_25cities.csv` 和 `field_dictionary.csv` 是覆盖与字段入口。

数值列描述**已合法就业、过了初始培训期、普通非农业且不收小费的受保护私人岗位**。特殊证书、补贴青年项目、公务/公共合同和更高行业工资另列。必须连同条件读取；工资标准不证明岗位可得，也不代表实际工资、可工作时数或家庭收入。城市规则依据工作地点，Census居住地名称不能代替岗位地址。

## 已核实的差别

- Seattle：2026普通工资21.30；14–15岁依据官方2018问答为85%，保留精确乘积18.105；16–17岁同成人。未把18.105冒充官方公布的美分整数。
- Washington DC：2026-07-01一般工资18.40、小费现金10.30；OAG明确未满18岁可按联邦工资7.25。未将一般成人标准填入未成年列。
- Las Vegas：Nevada批准规章R185-24AP于2026-04-29备案，仍分别排除未满18岁、非营利课后/暑期岗位和不超过90天的联邦青年培训情形。表中未成年7.25要求FLSA覆盖且已过初始期。2026公告的12.00适用于州法覆盖岗位。
- Denver：一般19.29；仅未解放、参加城市认证青年项目的未成年人可最多减15%。普通未成年人不能自动减15%。食品饮料小费抵扣最多3.02且必须实际收到。
- Chicago：当前市法6-105-020(b)(3)(F)规定未满18岁工资逐年追平；与2026一般17.05相结合，青年已并轨17.05。雇主4人门槛、两周内至少2小时、市法对初始期和营地的定义仍适用；州13.00青年工资不能直接代替芝加哥标准。
- Columbus：14–15岁7.25；受州更高工资覆盖的16岁及以上11.00。恰好405,000美元营业额在官方海报与新闻中表述冲突，主表选取大于该门槛的雇主情景。
- San Francisco：2026-07-01一般19.61；政府资助的真实课后/暑期培训或学徒项目未满18岁标准17.35。
- Los Angeles：2026-07-01一般18.42；14–17岁前160工作小时城市标准按85%并舍入到最近0.05，得15.65；仍须满足适用州底线，只有同时符合州learner条件才可用15.65，已有类似经验者州底线为16.90。酒店另有25.00现金及4.25健康福利义务。
- Charlotte：州法在联邦适用工资较低时恢复州底线，存在明确学生等例外。未机械套用联邦4.25。

## 来源和实际访问

`sources.json` 保存来源ID、官方URL、出版者及内容核验词。`access_log.jsonl` 逐次记录本机GET时间、HTTP状态、最终URL、文件路径、解析与内容验证阶段；HTTP200与有效工资内容分开。`source_access_latest.csv` 是最近一次实际结果。`web_evidence.json` 明确列出网页工具能够读到、但本机通道未必可读的官方事实。

原网页/PDF及解析文本只存 `raw_local/`，由本目录 `.gitignore` 排除。公开交付短事实、条件、URL和访问记录；没有认定原网页/PDF已获得整包再分发授权。日志中的本地路径描述采集机器现存证据，不代表原件已上传远端。

来源时点单独保留：Seattle年龄问答为2018；LA下载路径含2026但问答内页写2024-07；Indiana官方海报说明2009生效标准。Nevada2026海报表写2026-07-01、正文写2025-07-01，使用宪法确认的2024-07-01起12.00，并保留原文冲突。Oklahoma当前FAQ误写2000生效，联邦官方证实的2009日期优先。

## 尚存的真实缺口

各城市California160小时州learner规则与更高市法的全部交互、Seattle美分舍入、DC未成年小费/90天低工资组合、初始期与小费/特殊证书的叠加，以及全部行业、公共合同、职业豁免尚未穷尽。表中逐城列出具体缺口，不据此删城或补0。Jacksonville2026一般及小费数字已由官方网页索引/US DOL当前表核实，FloridaCommerce原页本机403；Florida特殊青年/证书适用仍须按具体岗位核对。

## 复现

先运行 `python projects/himcm2026A/analysis/collect_youth_wages.py` 下载官方来源；可在命令后指定来源ID分批下载。依赖已安装的PyMuPDF解析PDF，其他均为标准库。然后运行 `python projects/himcm2026A/analysis/collect_youth_wages_tables.py` 从人工核实的短事实重建主表、字典、覆盖及验证结果。后者不访问网络、不把抓取失败静默替换为虚构值。

人工编码依据仓库 `himcm-modeling/guides/modeling-workflow.md` 的数据来源、单位、缺失与事实/假设区分要求。没有生成城市排名。
