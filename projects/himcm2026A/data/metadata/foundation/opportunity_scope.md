# Historical validation reserve

Source: Opportunity Insights public statistical releases. S26, not S27 (S27 is Dryad).
The first tract file describes birth cohorts 1978–1983. The late-cohort file describes birth cohorts 1984–1989, and its current codebook states that standard errors in versions before June 2025 were corrected. URL upload-year 2024 is not its final revision date. Both files and standard errors/subgroups are preserved. Census-tract identifiers and supplied 2010–2020 crosswalk are not interchangeable with current city boundaries.

County outcomes are existing published statistics linked to each city's constituent counties. These are regional historical background; no county outcome is relabeled a city outcome. Relevant-county tract data are retained for a later explicit spatial crosswalk. No adult outcome is used to set present-day index weights or score values.
