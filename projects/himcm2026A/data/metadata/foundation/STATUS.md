# 人口、ACS、地域、成本与历史验证数据

采集日期2026-11-11。全部25城已提取，候选池采用Census V2025人口前25名，代码见`../cities.csv`。

## 实际取得

- **人口与地域**：官方全国CSV与排名XLSX交叉核对25城名次、人口；2020—2025分县人口精确合计到市。51个城市—县组合、50县；官方July2023都市区对应。当前城市GeoJSON和ACS2025城市多边形均保留，学校选择使用后者。
- **ACS**：2024/2025一年各21表、2020—2024五年11表，共53份原表；所有字段估计和90%MOE、表壳/变量定义、地域文件保留。25城字段长表38,000行。五年表另保留相关50县的tract/BG，县内社区集合不是城市精确社区集合。
- **ACS候选派生量**：850行，含租金负担30%/50%、车辆、宽带、青年就业/在校和贫困等；保存分子分母及来源字段。B23001青年就业直接覆盖25城；B14005额外保留在校×就业的更细分解。
- **BEA**：MARPP/MAIRPD全国2008—2024现成统计及定义；25城关联主都市区的分项价格与平减指数2,550行。Dallas/Fort Worth共享MSA；Oklahoma City有0.0118%人口属Shawnee微区，主MSA仅为区域背景，原份额保留。
- **HUD**：FY2024修订版与FY2027 FMR/SAFMR原XLSX、1983—2027历史CSV；51城市—县组合×5卧室规格×2版本=510行。Boston按HUD town细分匹配，未把Suffolk其他城镇租金误配Boston。相关FMR区全部ZIP小区域租金保留，未把整个FMR区ZIP称为市内ZIP。
- **Opportunity Atlas（S26）**：2018和2024晚出生队列tract现成表、county结果、社区协变量、官方2010—2020tract对应及代码本；50相关县约1.45万个tract。用于历史外部验证储备，未生成当代城市因果结论。

## 缺失、特殊值和可复现性

ACS原始一年B14005在2024有4城缺行、2025有6城缺行；2024 C16001有El Paso缺行，精确代码在`acs_coverage.csv`。五年B14005/C16001均覆盖25城，独立保留为不同时间窗口的补充，不冒充一年值。Census官方说明详细表存在质量过滤，不能把源表无行解释成城市数值0。

ACS数值特殊码与MOE特殊码分别保留，清洗值为空；受控人口的无MOE不解释成无人口估计。派生比例保留组件MOE，没有假设分项独立或伪造派生区间。家庭/学生/年龄分母不能互换；未拆分15—19岁来伪造14—18岁人口。

2024修订FMR工作簿含非法`docProps/core.xml`时间字符串；读取脚本仅在内存去除created/modified属性，原始文件未更改。所有数值来自实际单元格。

`archive_manifest.csv`记录原始与gzip路径、字节数和双方SHA256；无损压缩均已解压校验。`access/*.json`是逐请求证据。原始大文本以gzip归档，运行提取脚本前按清单恢复同路径文件。源码在`analysis/collect_foundation*.py`及`archive_foundation.py`。

本状态是数据取得和提取事实；是否已到GitHub以项目顶层归档清单和远端提交为准。
